indexgap init

command

Read the project and record what makes it different.

Works out where the pages are, the site URL, the content type and the dataset, writes indexgap.json, installs the agent skills into .claude/skills/ and adds the working files to .gitignore. Run once per project.

Usage

usage: indexgap init [-h] [--site SITE] [--content CONTENT]
                     [--profile PROFILE] [--dataset DATASET] [--key]
                     [--agents] [--force] [--lang {en,ru}]
                     [dir]

positional arguments:
  dir                project directory

optional arguments:
  -h, --help         show this help message and exit
  --site SITE        the site address, if it could not be worked out
  --content CONTENT  directory of pages
  --profile PROFILE  content type: catalog, events, ugc, product
  --dataset DATASET  keyword CSV
  --key              mint a new IndexNow key for this project
  --agents           create AGENTS.md for Codex if it is missing
  --force            overwrite an existing indexgap.json
  --lang {en,ru}     output language: en or ru. By default from INDEXGAP_LANG
                     or the system locale, otherwise English
