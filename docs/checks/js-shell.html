critical js-shell Indexing and reachability

The HTML a crawler receives contains no text at all — the page is drawn later by JavaScript. Search engines may render it eventually; the crawlers behind AI answers largely do not, and they see an empty document.

What indexgap reports

The finding reads:

critical  js-shell  в исходном HTML нет текста — его рисует JavaScript, а краулеры ИИ-поиска его не исполняют

How to fix it

This needs server-side rendering or prerendering: AI-search crawlers do not execute JavaScript. It is fixed in the site's build, not in the page's text.

How it behaves at scale

Reported per page even when it is common. Appearing on many pages is the nature of this finding rather than evidence of one template defect, so collapsing it would hide real work.

Finding it

pipx install indexgap
cd your-project
indexgap init
indexgap check
