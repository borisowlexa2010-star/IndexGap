Every check indexgap runs

59 checks across 8 families — 17 critical, 18 warning, 20 info. Each has its own page: what triggers it, why it is worth fixing, and the imperative fix the package hands to a person or an agent.

The list is generated from the package's own registry at build time, so it is the same set of checks the installed version runs — not a description of them.

Invented facts

The checks that compare what a page says against the data row that produced it. This is the part of the package that has no equivalent in a general site auditor, and the reason indexgap will not write page text for you: a generator that supplied the numbers could not then check them.

hreflang and language versions

hreflang is mutual, self-inclusive and per-page — three properties a template gets wrong in three different ways. These checks validate the cluster as a whole rather than the tag in isolation.

CheckLevelWhat it reports
translations-parkedinfotranslations parked
hreflang-missingwarninga page at the same path exists in another language (…), and this one declares no alternate at all. If it is a translation, link them with hreflang; if each market has its own text, there is nothing to link
hreflang-no-selfcriticalthe cluster has no link to this page itself — without a self-reference Google treats the whole cluster as invalid
hreflang-no-returncriticalthis page links to …, and that page does not link back. A one-way link is not “partly counted” — the whole link is discarded
hreflang-bad-codewarningthe “…” alternate has an empty href
hreflang-unknown-targetinfothe alternate … is not among the parsed pages — reciprocity cannot be verified
hreflang-lang-mismatchwarningthe self-reference is declared as “…” while the page declares lang=“…”
hreflang-canonical-conflictcriticalthe canonical points at a different language version (…) — that cancels hreflang: the engine will collapse the versions instead of showing the right one
hreflang-target-blockedwarningthe alternate … is closed to indexing, or its canonical points elsewhere — the cluster points at something that will not be in the index
hreflang-static-clustercritical… pages out of … declare the same set of alternates (…) and not one of them references itself. The template prints the home page's cluster on every page — as far as a search engine is concerned there are no links between the versions at all. Fixed once, in the template.
