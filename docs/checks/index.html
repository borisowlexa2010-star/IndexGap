indexgap Checks Commands GitHub

Every check indexgap runs

58 checks across 8 families — 17 critical, 18 warning, 20 info. Each has its own page: what triggers it, why it is worth fixing, and the imperative fix the package hands to a person or an agent.

The list is generated from the package's own registry at build time, so it is the same set of checks the installed version runs — not a description of them.

Invented facts

The checks that compare what a page says against the data row that produced it. This is the part of the package that has no equivalent in a general site auditor, and the reason indexgap will not write page text for you: a generator that supplied the numbers could not then check them.
