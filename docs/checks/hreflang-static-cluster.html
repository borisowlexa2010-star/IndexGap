hreflang static cluster

critical hreflang-static-cluster hreflang and language versions

Many pages declaring one identical set of alternates means the block was hard-coded into the template instead of being built per page. It is right for the page it was copied from and wrong for every other.

What indexgap reports

The finding reads:

critical  hreflang-static-cluster  … страниц из … объявляют один и тот же набор

How to fix it

The template prints the home page's cluster on every page. The cluster has to be built from the translations of THIS page.

How it behaves at scale

This is a site-level finding: it belongs to the site, not to any one page, and is reported once however many pages are audited.

Finding it

pipx install indexgap
cd your-project
indexgap init
indexgap check

Then indexgap brief turns every finding on this page into a work order placed next to the page it belongs to, with the thresholds the result has to satisfy.
